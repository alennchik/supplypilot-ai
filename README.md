# SupplyPilot AI

**AI-powered supply chain planning assistant for demand forecasting, inventory optimization, and intelligent decision-making.**

SupplyPilot AI is a Python-based project that aims to help businesses predict product demand, manage inventory, and make better supply chain decisions using machine learning and AI agents.

The project uses the Walmart M5 Forecasting dataset, which contains historical daily sales data from Walmart stores.

## Planned Features

- **Demand Forecasting:** Predict future product sales using historical sales data and machine learning.
- **Inventory Optimization:** Estimate reorder quantities, safety stock, and potential stock shortages.
- **AI-Powered Assistant:** Use LLM-based agents to analyze forecasts, explain inventory risks, and recommend actions.
- **Interactive Dashboard:** Visualize sales trends, demand forecasts, and inventory recommendations.
- **Model Evaluation:** Compare forecasting models using metrics such as MAE and RMSE.

## Tech Stack

**Currently used:** Python, Pandas, NumPy, PyYAML, Pytest, Ruff

**Planned:** Machine learning models, LLM APIs, and an interactive dashboard.
